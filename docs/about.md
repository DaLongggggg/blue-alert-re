# 关于本站

「蓝色警戒中文维基」是一个收录《蓝色警戒》（State of War, 2001）与《蓝色警戒II：战争狂人》（State of War: Warmonger, 2003）两作资料的**非营利粉丝维基**。两作内容混排收录、不按作品分目录，每个条目都以徽标标注归属：第一部 / 第二部；两作完全相同的资料只出一份。

## 站点结构

- **战役博物馆**：战役任务、教学任务与联机地图的资料页（任务简报、目标、难度、资料图与影片）。
- **单位图鉴**：建筑、工厂、防御、陆空单位与超级武器的图鉴页（说明、武器、属性表）。
- **新兵手册 / 武器一览**：面向新玩家的入门资料汇总。

## 数据来源

- 玩家自有游戏目录文件的离线整理：任务脚本（`tools/`）从本地游戏安装目录提取与解码数据，生成 `data/*.json`；提取过程不运行游戏程序本身。
- 社区公开整理的资料与攻略。
- 游戏附带的手册、制作名单等文本。

数据字段规范见仓库内 `research/DATA-MODEL.md`。
