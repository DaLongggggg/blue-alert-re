# 关于本站

「蓝色警戒中文维基」是一个收录《蓝色警戒》（State of War, 2001）与《蓝色警戒II：战争狂人》（State of War: Warmonger, 2003）两作资料的**非营利粉丝维基**。两作内容混排收录、不按作品分目录，每个条目都以徽标标注归属：第一部 / 第二部；两作完全相同的资料只出一份。

## 站点结构

- **战役博物馆**：战役任务、教学任务与联机地图的资料页（任务简报、目标、难度、地形底图、影片封面与关卡结构分布示意）。
- **单位图鉴**：81 个条目的图鉴页（游戏内说明与图像）；武器归属与数值属性尚未考证，页面如实标注。
- **新兵手册 / 武器一览**：两作说明书的整理与游戏内武器名表。

## 数据来源

站内每条事实都能追溯到具体出处，条目页末尾的「数据来源」列有程序地址、关卡文件或说明书章节。目前的全部数据来自两类来源：

- 玩家自有游戏目录文件的离线整理：脚本（`tools/`）从本地游戏安装目录读取并解码数据，生成 `data/*.json`；提取过程不运行游戏程序本身。
- 游戏附带的手册与程序内的制作名单等文本。

尚未考证的内容（如武器归属、部分单位的图像）页面标为「尚未考证」，不做推断。数据字段规范见仓库内 `research/DATA-MODEL.md`。
