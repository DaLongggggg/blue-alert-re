## 本站是什么

本站是《蓝色警戒》系列的**非营利粉丝资料维基**，统一收录两部作品：内容不按作品分目录，而是混排在一起，每条内容用徽标标注归属——

<GameBadge game="g1" /> 第一部《蓝色警戒》（State of War，2001）　<GameBadge game="g2" /> 第二部《蓝色警戒II：战争狂人》（State of War: Warmonger，2003）

两作共有的内容（如教学模式、界面资料图）会同时显示两个徽标。

站点由「战役博物馆」与「单位图鉴」两大部分组成：

- **[战役博物馆](/museum/)**：34 个战役关（第一部 23 + 第二部 11）、1 个教学模式、14 张联机地图。每关收录简报战况、任务目标、基地代号、领土、难度（按游戏原文），并配关卡地形底图、简报影片（或封面）与关卡结构分布示意图。
- **[单位图鉴](/units/)**：两作通用的 81 条单位 / 建筑与武器资料，按分类浏览。

## 数据从哪里来

站内数据不是道听途书，每条事实都能追溯到玩家自有游戏文件的整理结果（仓库 `data/*.json` 与 `research/manual-*.md`）：

- **任务简报、任务目标、基地代号、领土、难度**——从两作游戏程序的数据段与关卡文件中逆向提取、逐条注明出处（共 49 个任务条目）；
- **关卡地形底图、结构分布示意、界面资料图、简报与片头片尾影片**——从游戏文件中提取（仓库内 `tools/extract_media.py` 可复现；影片体积大，不随站点发布，页面显示封面）；
- **制作名单**——游戏程序内的名单数据；
- **说明书**——两作中文说明书全文整理（仓库 `research/manual-g1.md`、`research/manual-g2.md`），剧情背景等页面直接引用其原文。

对拿不准的内容（如无官方名的关卡、译名不一致处），页面会如实注明「编写中」或「原文如此」，宁可留空也不编造。
