# 新兵手册

面向初次接触《蓝色警戒》系列的玩家。本页整理自游戏附带说明书（《蓝色警戒》ReadMe.doc）：鼠标操作、热键、主菜单、界面说明与提示诀窍。**以下各节文字两作说明书完全相同**（第二部说明书沿用第一部文案），故同时标注两部作品；引文均照录原文，明显的错字/怪异表述不作改动，需要说明处以〔原文如此〕标出。

## 鼠标设置

**鼠标左键：**

- 选择作战单位：单个或多个
- 移动：选择作战单位或飞碟，并在地图上点击它们的目的地
- 袭击：点击想要袭击的敌人的作战单位
- 推动袭击：按 CTRL、ALT，然后点击敌人的作战单位
- 增加作战单位：按 SHIFT，然后点击单个的作战单位
- 资料框：选择一个建筑或炮塔

**鼠标右键：**

- 取消：取消所有的选择（包括建筑物、炮塔和资料框）
- 快速浏览：按住右键，快速在地图上拖动

## 主菜单

- **新游戏** － 单人游戏中玩家的任务是，作为整个游戏的司令官，你必须在22次任务中取胜，最终夺取超级防线。你的作战单位是蓝色的，敌人的作战单位是绿色的。
- **读取游戏** － 读取已保存的游戏（仅适用于单人游戏）。
- **教练课程**〔原文如此，主菜单按钮上作「教学模式」〕 － 学会蓝色警戒基础知识的一条简易途径。建议所有的玩家都能熟悉该游戏的独特基础知识。
- **多人游戏** － 通过网络运行游戏。第一个玩家是服务器（蓝色），其它的是客户（绿色），可以参加该游戏。建议起连接后〔原文如此〕，服务器可以在左边的窗口处选择要执行的任务。访问我们的站点，可以获取更多的多人游戏任务。每个多人游戏的任务可以通过增加金钱，研究指数，或调整大量的空中作战力量来调整成单人游戏的任务。
- **选项** － 控制许多选项，显示效果和音效。如果游戏运行得很慢，就显示不出战场上烟雾弥漫的效果了。
- **退出游戏** － 退出游戏。

## 主屏幕（界面说明）

说明书对主屏幕各区域的说明如下（编号照录原文，其中「金钱」与「研究指数」都标作 1〔原文如此〕）：

1. **金钱** － 显示可用金钱的数量。你可以通过金矿赚得金钱。金钱是建筑炮塔的必须品。
1. **研究指数** － 显示太阳能搜集器制造的研究指数。研究指数是提高工厂生产的陆地作战单位的重要因素。
2. **空中力量图标** － 显示可用的空中作战单位数量。
3. **信息提示** － 在这里公布大量的即时信息。
4. **炮塔图标** － 显示各种可用的炮塔。
5. **设施图标** － 显示当前选定的建筑图标。记住！这是你可以用来升级作战单位的技术水平的唯一地方（橙色的方向箭头）。
6. **雷达和资料框** － 资料框能显示选定单位或建筑的资料。当资料框不能用时，雷达就是可用的了。左键单击雷达，屏幕上会显示出选定区域的地图，右键单击，会使地图的背景变黑。
7. **剩余时间** － 显示特殊事件所剩余的时间援军，任务结束，等〔原文如此，疑脱「（」〕）。在一些任务中，它是很有用的。

## 提示和诀窍（原文作「决窍」）

- **集结指分**〔原文如此，即「集结指令」〕：选择工厂，然后按"R"键设置一个研究指数（或你可以使用作战单位图标的图标）。然后，左键在地图上单击，设置一个新近制造的作战单位的搜集地点。这是多么巧妙地设置，不是吗？
- **全球作战单位的选择**：熟悉它们，可以提高你的速度！
  - 数字键 <code>/</code> － 选择所有的防空作战单位
  - 数字键 <code>&#42;</code> － 选择所有看得见的坦克和防空作战单位
  - 数字键 <code>-</code> － 选择所有看得见的坦克
  - 数字键回车 － 返回已选择的作战单位
- **飞碟热键**：飞碟是游戏中最重要的作战单位，它可以在你的操纵下进行有效的飞行：
  - 数字键 <code>+</code> － 直接选择飞碟
  - 数字键 <code>+</code> and LMB － 优先指挥飞碟
  - 数字键 <code>+</code> and 数字键回车 － 居中观察飞碟
- **定义战略位置**：使用 SHIFT + "数字键1-9"，你可以在地图上设置九个战略点，并可按住各自相应的数字键快速在它们中切换。
- **返回上一则信息**：这对于你返回上一则信息事件是很有效的。学会使用它吧！例如：当信息是"建筑陷落"时，按住"空格键"或"数字键0"，它就会自动居中化。
- **长射程武器**：一些作战单位，象炮兵和超级机器人能够有效地杀死偏远地方的敌人。它们对于毁坏敌人的炮塔和建筑是很有效的。
- **战斗机**：唯一一种可以不被防空设施（防空作战单位和防空炮塔）毁掉的作战单位。在最初的袭击中使用它，可以大大减少敌人剩余防空单位对你方的伤害。
- **飞碟生成**：这则信息的意思是生成了一个可用的飞碟。记住：飞碟可以修复你的炮塔，也可以一直旋转毁坏敌人的炮塔。
- **卫星防御**：一些建筑或炮塔可以在卫星防御系统下，免受飞碟的袭击。用飞碟是不会占领这些建筑的。
- **推动袭击**：所有的陆地作战单位可以毁坏以下的目标：作战单位，炮塔和建筑。用推动袭击（袭击时，按 CTRL 或 ALT）可以优先消灭目标。

## 怎样使游戏运行得更快

- 在开始游戏前，使所有程序和效果不再显示。
- 如果你的处理器或2D图象板速度减慢了，你可以在选项中删除云雾效果。
- 如果 Windows 经常在启动时切换到低的图象效果，那么，推荐玩家至少要用64兆内存。
