# 单位图鉴

这里收录《蓝色警戒》两部作品程序内单位与建筑名称表中的全部条目，统一收录、不按作品分目录，每个条目以徽标标注归属作品。有游戏内图像的条目直接显示精灵图或资料框影像；武器归属与数值属性尚未考证的，页面如实说明。

<UnitExplorer />

## 收录范围与分组

本图鉴收录两作程序内单位/建筑名称表中的全部 **81 个条目**。两作的单位 ID、中文名、英文名与资料框说明完全一致（程序内两作同表），因此统一收录、不按作品分目录；每个条目页以徽标标注归属作品。

条目按「收录分组」整理，避免武器名、界面元素混在单位与建筑里：

| 分组 | 条目数 | 说明 |
| --- | --- | --- |
| 作战单位 | 24 | 陆战单位、空袭单位、特种单位（含飞碟）与超级武器 |
| 建筑与防御 | 22 | 基地建筑、工厂与炮塔（含 Top Sentry） |
| 生产模式 | 9 | 金币/研究指数/能量流入 1–3（建筑生产模式，ID 16–24） |
| 武器名表条目 | 25 | 游戏内武器名表原文（英文，未汉化），集中在[武器一览](/units/weapons) |
| 其他收录 | 1 | 缩略地图（界面元素） |

## 游戏内 ID 空间

两作的单位 ID 同表，ID 段与内容如下（每个条目页的「游戏内 ID」都会标注所属段）：

| ID 段 | 内容 |
| --- | --- |
| 1–15 | 陆战单位：防空设施、炮兵、装甲坦克、喷火器、特派坦克各轻/中/重三级 |
| 16–24 | 建筑生产模式：金币流入 1–3、研究指数流入 1–3、能量流入 1–3 |
| 25–29 | 炮塔：防护大炮、防空设施、离子炮塔、莱德风暴、集束炮塔 |
| 30–34 | 空袭：轰炸机袭击、运兵飞船、战斗机袭击、连环轰炸机轰炸、星体炸弹风暴 |
| 40–46 | 特种单位：飞碟、超级机器人（科迪亚克/空对空复仇者/美洲狮/格林机关炮/阿基里斯）、罗根炸弹 |
| 100–108 | 建筑：总部、轻/中/重型工厂、飞机生产基地、金矿、太阳能搜集器、风能搜集器、机器人工厂 |
| 109–113 | Top Sentry 塔炮 G10–G50 |
| 115 | 缩略地图（界面元素） |

## 分类说明

| 分类 | 说明 |
| --- | --- |
| 建筑 | 基地建筑与功能设施（总部、金矿、太阳能搜集器、风能搜集器） |
| 工厂 | 生产单位的车间（含飞机生产基地、机器人工厂） |
| 防御 | 防空设施、炮塔与 Top Sentry 塔炮 |
| 地面单位 | 坦克、炮兵、喷火器、特派坦克与超级机器人 |
| 空中单位 | 空袭单位与飞碟 |
| 超级武器 | 星体炸弹风暴、罗根炸弹 |
| 其他 | 武器名表条目与缩略地图（界面元素） |

各分类的独立列表页见侧边栏「单位图鉴」分组。
