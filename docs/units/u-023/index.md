**分类**：防御设施 · **收录分组**：建筑与防御 · **游戏内 ID**：26（ID 段：25–29（炮塔））

发射四枚对空导弹的防空炮塔

## 说明

这种防空系统能发射四个地对空导弹，因此它能攻击飞碟和空中轰炸机等。但它不能打击陆地作战单位。
