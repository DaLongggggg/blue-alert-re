# 第 05 关

<MissionMeta id="g2-m06" />

## 战况

在地图的北方，发现了储量丰富的黄金矿藏。敌人在设法接管，并且在此区域调集了大量的军队。我方的军队也正在赶往那里，在他们到达之前，要注意保护我们设在附近的基地。这项任务并不轻松，敌方有着庞大的进攻力量，并且很快就有了5个飞碟。

## 任务目标

- 任务：尽量多的控制金矿，坚持用炮塔保护我们的基地35分钟。
