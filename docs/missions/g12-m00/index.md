# 教学模式

<MissionMeta id="g12-m00" />

## 教程课程

- 欢迎你来到蓝色警戒教练课堂。请点击右边的箭头继续课程。

1. 点击右边的箭头环视整个地图。
2. 你也可以用方向键环视整个地图。

- 课程A: 飞碟。

3. 这是你的飞碟。选择它，然后点击目的地来移动飞碟。

- 飞碟是最重要的作战单位。它有三个基本特征。可以用它来占领，升级，修理。

4. 现在试着占领这个轻型工厂。选择飞碟，然后点击工厂。
5. 这个轻型工厂会制造出陆地作战单位。它们的制造是自动的，不用花费任何东西。请等到进度条满。

- 同时，为了制造出更多的作战单位，你也可以用飞碟升级工厂。绿色箭头的显示表示可以升级工厂了。现在，升级这个轻型工厂。

6. 飞碟也可以修理被破坏的建筑。（请按鼠标右键切换修理和升级模式，修理这个建筑。）

- 课程B:炮塔。
- 这是你的金矿。你可以用制造的金钱来生产保护建筑的炮塔。你也可以升级这个建筑。它会加速你的金钱的流入。

7. 现在，你有足够的钱建造你的第一个炮塔了。当敌人在炮塔射程内时，炮塔会自动向敌人射击。点击炮塔图标，把它放在建筑的附近，毁掉敌人的作战单位。

- 课程C:空中力量.

8. 这是空中单位生产基地。你可以使用它生产出空中力量。请等到进度条满。
9. 点击图标。
10. 用它去轰炸敌人的作战单位。只用几次，你就会把敌人全部消灭。

- 课程D:技术水平。
- 这是你的轻型工厂。它能制造轻型作战单位。它也可以制造更强的中型作战单位，但它需要研究指数来提高它的技术水平。

11. 现在你拥有了400研究指数。要获得更多的研究指数，你必须占领位于下方的太阳能搜集器。
12. 现在，选择轻型工厂，注意屏幕右边的作战单位图标。当你有500分的时候，就可以升级你的工厂了。技术水平图标会显示在作战单位图标的旁边。
13. 现在，点击技术水平图标，一种新的武器会自动开始制造。

- 课程E:最后的任务。

14. 这是你的总部。任务是毁掉敌人的基地。
15. 哦，一些建筑有卫星保护系统。所以你应该用陆地作战单位攻击这些建筑。占领这些工厂，然后，毁掉敌人的基地。
16. 很好！你成功地掌握了全部课程。

## 任务目标

教学关没有独立的任务目标文字；上方课程即游戏内的全部教学内容。

## 注意

课文顺序按 .data 内存地址倒序重建（首锚点 0x4a22cc 欢迎语、尾锚点 0x4a1c80 结束语）；'i ' 开头为课程标题/讲解，'! ' 开头为操作步骤。两作 M00 关卡文件完全相同，g2 教程文本（0x49ed38 起）与 g1 相同。
