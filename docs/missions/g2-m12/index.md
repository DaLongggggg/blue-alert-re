# 第 08 关

<MissionMeta id="g2-m12" />

## 战况

这块地方叫做黄金谷，有着丰富的黄金和矿物储量。我们的陆地力量目前正在此地区运转，所以我们不能依靠他们的帮助打击敌人。然而在这个任务中，你有大量的炮塔，可以利用他们有步骤的破坏敌人的总部。

## 任务目标

- 任务：用尽所有的金钱修建炮塔，消灭敌方的总部。
