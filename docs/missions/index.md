# 任务列表

全部已收录任务的索引：战役任务（campaign）、教学任务（tutorial）与联机地图（network）统一列出，可用筛选器按作品与类型过滤。每个任务的详细资料页位于 `missions/<id>/`。

## 标题与字段说明

- 战役关标题「第 NN 关 · 战场：XX」：NN 是简报里的**领土号**（第一部）或领土序号（第二部，与文件号不同）；XX 是简报「战场：」行里的地名。第二部简报没有战场行，标题只有「第 NN 关」。战役关没有官方关卡名，站点不代拟。
- 「难度」按游戏原文展示：第一部为数字；第二部为「N / 10」制。
- 联机地图用官方中文名（第一部 8 张，出自说明书）或文件名 slug（第二部 6 张，说明书无联机章节）。
- 教学模式为两作相同的教程关（M00），带双徽标。

任务页的媒体说明：地形底图与结构分布示意图已随站点发布；简报影片体积大、未随站点发布，线上显示封面（详情见各任务页）。
