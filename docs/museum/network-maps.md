# 联机地图

两作的联机对战地图统一收录在任务数据（`data/missions.json`，类型 `network`）中，共 14 张，以地图文件名的 slug 作为编号。两作的联机图**没有可提取的地形图与影片**，每个任务页收录的是说明书说明与文件信息。

关于名称：

- <GameBadge game="g1" /> 第一部的 8 张联机图有**官方中文名**，出自第一部说明书「多人游戏任务」节——说明书按 01–08 顺序列出中文名与说明，编号与 `Data/Levels/` 下 `.net` 文件名的前缀一一对应（热身行动、暴风雪、淘金热、大扫荡、原子弹行动、流星风暴、战火篇、岛屿之命）。
- <GameBadge game="g2" /> 第二部的 6 张联机图**没有官方中文名**：第二部说明书没有联机地图章节（其余章节沿用了第一部的文案）。站点如实使用文件名 slug 作为标题，不代拟译名。

## 联机方式（说明书原文）

以下为第一部说明书关于联机的说明（第二部说明书对应文字相同）：

> 多人游戏－通过网络运行游戏。第一个玩家是服务器（蓝色），其它的是客户（绿色），可以参加该游戏。建议起连接后，服务器可以在左边的窗口处选择要执行的任务。访问我们的站点，可以获取更多的多人游戏任务。每个多人游戏的任务可以通过增加金钱，研究指数，或调整大量的空中作战力量来调整成单人游戏的任务。

::: tip 原文照录
说明书「多人游戏任务」节的个别用字有错漏（如「中选」「能难取胜」），站点在任务页引用时一律照录原文，不代改；错处可对照各任务页的说明文字。
:::
